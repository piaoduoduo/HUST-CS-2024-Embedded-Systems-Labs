# 游戏工坊 v1 新增源码

这里直接保存 `arcade`、`lab6_gomoku` 和测试代码，便于 GitHub 上阅读。课程框架的修改位于 [完整重建配置](../../labs/arcade-v1/profile.json)，不要把本目录当作含所有依赖的独立工程。

构建步骤见 [游戏工坊说明](../../labs/arcade-v1/README.md)。主机规则测试可从仓库根目录运行 `python3 tools/test-game-core.py --cc gcc --version 1`。

`tests/offline.py` 是保留的历史 Windows 全界面测试脚本，其课程字体路径和相邻历史目录需要按原工作区准备。当前跨平台核心规则检查使用仓库根目录的测试入口。
