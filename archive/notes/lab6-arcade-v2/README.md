## 现在可以怎么玩

双击 **电脑试玩.cmd**。鼠标模拟触摸，Esc 回菜单。2048 按住棋盘滑动；打砖块按住拖动挡板，松开发球。电脑模拟器现在会保存挑战纪录，五子棋对局仍不写存档。

### 三关打砖块

第一关普通砖阵，第二关交错阵型，第三关前排加入需击打两次的砖块。过关后点击“进入下一关”，保留分数和生命；三关清空后提示全部通关。

连续破砖会增加连击：第 n 块得 10×min(n,8) 分，触到挡板或漏球重置连击；耐打砖第一次受击记 2 分。每累计击破五块砖、且屏幕当前无道具时，掉落一个道具，依次循环：

| 标记 | 效果 |
|---|---|
| 宽 | 挡板加宽，持续 10 秒 |
| 缓 | 球速降为 68%，持续 8 秒 |
| 盾 | 抵挡一次漏球；不会叠加多个护盾 |

用挡板接住道具才会生效。暂停、返回菜单和重开确认时，游戏时间停止。漏球清除加宽与减速，护盾在抵挡时消耗；切到下一关时清除道具效果。

视觉新增圆球拖尾、击砖碎片、连击字样、道具倒计时、护盾线和耐打砖描边。视觉粒子最多 64 个、拖尾最多 12 个点，不随运行时间增长。

### 2048

- 撤销一步恢复棋盘、分数和随机数状态；撤销后重复同方向，结果相同，不能靠反复撤销刷不同随机数。
- 局面提示枚举当前四个方向，以及随机生成 2/4 后的下一步选择；按空格数量、相邻数字差和大数字靠角等因素评分。只显示建议，不代替用户走棋，不保证获胜。
- 移动后的变化格短暂亮边。得分纪录与 2048 徽章不会因撤销或重开而撤回。

### 挑战纪录与五枚徽章

保存 2048 最高分、打砖块最高分、最佳连击；徽章为达到 2048、五连击、第一关、第二关和三关全通。预览图片里的分数是明确设置的测试样例，不是实际取得的成绩。

只保存挑战纪录，2048 和打砖块的局内状态仍仅保存在当前进程。板端切入五子棋会退出合集进程，返回后这两个小游戏重新开局；Windows 模拟器的进程内状态会保留。五子棋继续沿用旧版功能与独立存档。

## 文件与兼容性

- Windows 试玩：`电脑试玩.cmd` 调用 `build/arcade-simulator.exe`，依赖同目录 `build/assets` 字体资源，不能只移动 EXE。
- Windows 纪录：`arcade-records-v2-simulator.txt`。
- 开发板纪录：`out/arcade-records-v2.txt`。
- 开发板五子棋独立存档：`out/arcade-gomoku-save.txt`。

纪录有版本标识、字段范围检查和校验和。采用临时文件、刷新写入、替换目标文件；Windows 使用 MoveFileEx，Linux 使用 rename 并同步所在目录。损坏或不可读的旧记录不自动覆盖，本次会话暂停保存并显示提示。不能把这些实现描述为已验证突然断电安全；这仍需板测。

Windows 模拟器有单实例互斥，板端请通过配套脚本的 flock 单实例锁启动。不要同时运行 v1、v2 或其他绘制 framebuffer 的实验程序。不要在程序运行时编辑其纪录文件。

## 下次上板

将 `resources/lab6-arcade-v2-board-source.tgz` 上传开发板，解压到单独目录。

```bash
cd lab6-arcade-v2
bash build-on-board.sh /开发板上的实际课程项目路径
bash run-on-board.sh
# 无法自动识别触摸时再指定：
bash run-on-board.sh --touch /dev/input/eventN
```

课程项目路径下应有 `out/font.ttc` 与 `common/external`。构建只写新目录，按课程 root SSH 环境运行。脚本临时停止开发板的显示管理器，并在退出时恢复此前运行的显示管理器，不修改开机启动配置。

建议验收顺序：菜单选择 2048 → 滑动/撤销/提示 → 打砖块发球/拖动/暂停 → 实际接道具 → 通关切换 → 回菜单查看纪录 → 退出重开验证纪录 → 五子棋落子与电脑回应 → 退出确认桌面恢复。真实三关难度、触摸手感与帧率需要在板上调整。

## 代码与工作量

新增的 `arcade/breaker.c` 管理关卡、固定步长物理、道具和效果；`profile.c` 管理持久记录；`engine.c` 处理 2048 规则与提示；`app.c` 处理手势、撤销和菜单；`render.c` 绘制界面。五子棋与 common 继续复用此前版本。

打砖块仍用 240 Hz 固定物理步长，最多补算 100 ms。每子步检查 B 个砖块和固定上限 P 个粒子，O(B+P)。提示在固定 4×4 棋盘上有明确枚举上限，不是深度不限的搜索。20 ms 绘图定时器只是目标间隔，不代表已测得 50 FPS。

当期任务依据与参考来源沿用 v1：PPT 第 88 页允许复杂单机程序；[往届五子棋项目](https://github.com/nivag8899/HUST-Embedded-System) 用于功能组织参考；[1037.wiki](https://1037.wiki/) 上一轮仅取得导航，未取得新报告正文。本次新增游戏逻辑独立实现，没有将别人测试结果当成本项目结果。新增玩法与成绩没有明确换算关系，最终以当期验收为准。
