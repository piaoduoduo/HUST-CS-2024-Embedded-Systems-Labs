# 实验六升级：橙派游戏工坊 v1

2026-10-30。当前交付为离线准备版，未接开发板测试，未由助教验收。原来已试运行的五子棋代码、日志、报告和公开仓库均未修改。

## 三个游戏

- 五子棋：复用已试运行版本的人机 AI、同屏双人、悔棋和存档。合集使用独立存档，原来的对局文件不会被覆盖。
- 2048：四方向滑动合并；同一步内每块数字至多合并一次；有效移动才生成数字；得分、达到 2048 和无可用移动提示。
- 打砖块：50 块砖，三条生命，拖动挡板、松手发球；不同击球位置改变反弹方向；暂停、胜负、重新开始确认。

统一入口支持切换游戏和退出。2048 与打砖块在当前合集进程内保留进度；启动五子棋会结束合集进程，返回后这两个小游戏重新开始。这两款小游戏目前没有断电存档。Windows 模拟器内所有游戏都不写存档。

这版重点是本地触摸交互、规则与实时物理；未加入音频游戏或双设备联机，也没有把这些算作已完成功能。

## 电脑立即试玩

双击本目录的 **电脑试玩.cmd**，不要单独搬走 EXE：它需要本目录 build/assets 中的字体模拟资源。

- 鼠标点击模拟单指触摸；2048 按住并滑动；打砖块按住拖动挡板、松开发球。
- 五子棋沿用原有按钮；电脑模拟器按 Esc 可随时回菜单。
- 标题栏注明 HOST SIMULATION。五子棋显示存档暂停是预期行为，模拟器不会覆盖真实存档。
- 模拟器复用实际 C 规则和绘图代码，字体使用 Pillow 生成的掩模；不能证明板端 FreeType、触摸输入、帧率或 ARM 二进制已通过。

## 下次上板

将单独的 `lab6-arcade-v1-board-source.tgz` 解压到开发板上的新目录，不要覆盖旧项目。确认旧实验进程已经退出。

在解压目录执行（将参数换成开发板上实际课程项目路径，该路径下应有 out/font.ttc 和 common/external）：

```bash
bash build-on-board.sh /实际路径/lab-st-2026
bash run-on-board.sh
# 自动识别触摸失败时：
bash run-on-board.sh --touch /dev/input/eventN
```

构建只写新目录。依赖课程镜像的 GCC、make、字体、JPEG/PNG/FreeType/ALSA 等原有库。运行需要访问 framebuffer、触摸设备和停止显示管理器的权限；课程 root SSH 环境可直接运行。脚本暂时关闭开发板图形桌面，退出后恢复原先运行的显示管理器，不修改开机启动配置，也不涉及 Windows 桌面。

合集与五子棋通过进程交接独占显示，避免同时绘图；日志放在 logs，独立五子棋存档位于 out/arcade-gomoku-save.txt。合集自身有 flock 单实例锁，但不能阻止另一个旧版实验进程绘制屏幕，启动前应先退出旧程序。

## 已执行的离线验证

运行 `python tests/offline.py` 可重做（Windows，需 Python/Pillow、课程字体与 MSYS2 UCRT64 GCC；ARCADE_CC 环境变量可指定编译器）。

- GCC 使用 `-Wall -Wextra -Werror` 编译规则、应用、渲染与 Windows 模拟器。
- 8,000 次生成的 2048 移动验证数字合法性、数字总量变化；另有重复合并禁止、无效移动不消耗随机数、死局判断用例。
- 打砖块验证墙面反弹、挡板反弹、砖块移除、漏球扣命、终局、暂停与固定步长一致性。
- 菜单、重开确认与多指所有权验证。
- 六个界面状态调用实际渲染代码，检查 framebuffer 前后保护区与行跨度填充未被改写。
- 原版源码哈希保持不变。

`test-results/result.json` 和对应日志为本轮证据。`preview` 中图片均为电脑模拟，不能用作真实板测截图。

## 技术说明

- 2048 每次移动扫描固定 16 格；若推广到 N×N 棋盘，时间复杂度 O(N²)，辅助空间 O(N)。
- 打砖块用 CLOCK_MONOTONIC 测时间、240 Hz 固定物理步长；每个子步检查 50 个砖块，复杂度 O(B)，B 为砖块数。速度约 300–320 像素/秒，单步位移约 1.3 像素，小于球和砖块尺寸。OS 卡顿最多补算 100 ms，避免长时间追帧；代价是严重卡顿时游戏时间会放慢。
- 实际绘制由 20 ms 定时器驱动，这是目标更新间隔，并非已测到 50 FPS。静止和暂停画面不持续重绘。
- 图形、触摸和五子棋来自本项目先前版本；新的规则、应用状态、界面和桌面模拟器独立放在 arcade、tests 中。
